# لوحة إدارة المنصة (محلية)

لوحة منفصلة عن نظام المنشآت. منها تدير المنصة كاملة: المنشآت وطلبات تسجيلها، والاشتراكات والفترة التجريبية، والباقات والأسعار، والفواتير والمدفوعات ورصيد كل منشأة، والإعلانات، وإعدادات المنصة، وسجل العمليات.

- **تعمل على جهازك فقط:** على العنوان `http://127.0.0.1:5180`، ولا تُفتح من الشبكة.
- **لا تُنشر على أي استضافة.**
- **بلا شاشة دخول:** تدخل تلقائيًا بحساب مدير المنصة المحفوظ في `.env.local` على هذا الجهاز.
  - كلمة المرور يقرؤها خادم اللوحة المحلي (`npm run dev`) ولا تصل إلى كود المتصفح.
  - المتصفح يأخذ رموز الجلسة فقط، ومن صفحة اللوحة نفسها على `127.0.0.1` فقط.
- **الصلاحية من قاعدة البيانات:** كل عملية تمر بدوال `platform_*`، وهي ترفض أي حساب ليس في جدول `platform_admins`.

## التشغيل أول مرة

1. افتح نافذة PowerShell داخل المجلد:
   ```
   cd D:\admin_alayaf-copy
   npm install
   copy .env.example .env.local
   ```
2. افتح `.env.local` بالمفكرة واملأ القيم:
   - `VITE_SUPABASE_URL`: رابط المشروع الجديد (موجود في الملف).
   - `VITE_SUPABASE_ANON_KEY`: المفتاح العام (anon). تجده في Supabase ← Project Settings ← API.
   - `PLATFORM_ADMIN_EMAIL` و`PLATFORM_ADMIN_PASSWORD`: بريد حساب مدير المنصة الذي أضفته إلى `platform_admins` وكلمة مروره.
   - **مهم:** الاسمان بلا `VITE_` في أولهما. لو كتبتهما بـ `VITE_` تدخل كلمة المرور في كود المتصفح.
3. شغّل اللوحة:
   ```
   npm run dev
   ```
   ستُفتح اللوحة في المتصفح تلقائيًا.

## ملاحظات أمان

- `.env.local` فيه كلمة مرور مدير المنصة. لا ترسله لأحد، ولا تضعه في أي مستودع (هو مستثنى في `.gitignore`).
- **كلمة المرور نفسها تعمل من أي مكان على Supabase**، لا من هذا الجهاز فقط:
  - اجعلها طويلة وخاصة بهذا الحساب وحده.
  - لا تستخدم بريد مدير المنصة لأي منشأة.
- لا تستخدم مفتاح `service_role` هنا. المفتاح العام يكفي، والصلاحية تحسمها قاعدة البيانات.
- ليس في اللوحة أمر `build`: لا تُرفع إلى Netlify ولا إلى أي استضافة. الدخول التلقائي يعمل من `npm run dev` فقط.
- **حماية إضافية (اختيارية لاحقًا):** التحقق بخطوتين (MFA) لحساب مدير المنصة. تفعيله يلغي الدخول التلقائي، فنعدّل اللوحة معه حين تقرر.

## ما في اللوحة (بعد S15)

> تحتاج اللوحة أن يكون `S15-saas-subscriptions.sql` مطبّقًا على القاعدة. قبل تطبيقه تعمل صفحة «المنشآت» فقط، ويظهر تنبيه في أعلى الصفحات.

**القائمة الجانبية:**
- **الرئيسية:**
  - الإيراد الشهري المتكرر قبل الضريبة (الشهري بسعره، والسنوي مقسومًا على 12) والسنوي، وتوزيع المشتركين على الباقات.
  - أرقام: المشتركة، والتجربة، والتجارب القريبة من الانتهاء، والقراءة فقط، والمستحقات، والمحصّل هذا الشهر، ونسبة التحويل من التجربة، والجديدة، والمجانية.
  - ما يحتاج إجراءً اليوم: طلبات التسجيل (موافقة أو رفض)، والتجارب التي تنتهي خلال 3 أيام أو انتهت (تمديد أو تفعيل)، وطلبات الاشتراك، والأرصدة المستحقة.
- **المنشآت:** التسجيل والموافقة والرفض والإيقاف وإعادة التفعيل، مع الباقة وحالة الاشتراك والرصيد لكل منشأة. وزر «منشأة جديدة».
- **طلبات الاشتراك:** ما ترسله المنشآت من صفحة «الاشتراك» في النظام. التفعيل من صفحة المنشأة يغلق الطلب تلقائيًا.
- **الاشتراكات:** كل منشأة بباقتها وحالتها ونهاية فترتها واستخدامها ورصيدها، مع تصنيفات (التجربة، القريبة من الانتهاء، القراءة فقط، المشتركة، المتأخرة، المجانية، عليها رصيد، لها طلب).
- **الفواتير والمدفوعات:** كل فواتير المنصة ومدفوعاتها، مع الطباعة والتصدير CSV.
- **الباقات والأسعار:** تعديل الباقات الثلاث أو إضافة باقة: السعر الشهري والسنوي، وحدود المستخدمين والموظفين الفعّالين والفروع (فارغ = بلا حد)، والمزايا التي تظهر للمنشأة، والإظهار والتعطيل.
- **الإعلانات:** شريط يظهر أعلى صفحات النظام لكل المنشآت أو للتجربة أو للمشتركين أو للقراءة فقط، بمدة بداية ونهاية.
- **الإعدادات:** أيام التجربة (7)، ومهلة السماح بعد انتهاء الاشتراك المدفوع (7)، وباقة التجربة، ونسبة الضريبة، وبيانات المنصة على الفواتير (الاسم والرقم الضريبي والبنك والآيبان)، والتواصل وتعليمات الدفع التي تراها المنشآت.
- **سجل العمليات:** كل عمليات المنصة والمنشآت والاشتراكات والفوترة، مع تصنيف وبحث.

**صفحة المنشأة** (من أي اسم منشأة):
- **الاشتراك:**
  - الأيام المتبقية والباقة والحالة والتواريخ، والاستخدام مقابل حدود الباقة، والرصيد.
  - تفعيل أو تجديد اشتراك مدفوع: الباقة والدورة وعدد الأشهر أو السنوات، والبداية (الآن أو بعد نهاية التجربة أو الفترة الحالية)، وسعر خاص وخصم، وإصدار فاتورة بالضريبة، وتسجيل الدفعة المستلمة.
  - تمديد التجربة أو الفترة بأي عدد أيام (من يوم إلى 365).
  - تغيير الباقة، والقراءة فقط الآن، والمجاني الدائم، وإيقاف التجديد، ومتأخر السداد، والإرجاع إلى «مشترك».
  - طلب الاشتراك المفتوح (تفعيل حسب الطلب أو إغلاقه)، وملاحظات داخلية لا تراها المنشأة.
- **الفوترة والرصيد:** الفواتير (طباعة وإلغاء بسبب)، والمدفوعات (إلغاء بسبب)، والتسويات. وإصدار فاتورة يدوية، وتسجيل دفعة، وتسوية رصيد (رصيد للمنشأة أو مبلغ عليها).
- **بيانات المنشأة:** كل البيانات ومنها المنطقة. الدولة تظهر ولا تتغير. تغيير الاسم أو الرقم الضريبي أو السجل يطلب تأكيدًا.
- **المستخدمون:** تعطيل وتفعيل وإزالة عضو معطّل.
- **سجل العمليات** الخاص بالمنشأة.

**كل نوافذ التأكيد داخل اللوحة** (لا `window.confirm`)، وكل تعديل يُسجَّل في سجل العمليات باسم مدير المنصة.

## الاشتراكات: كيف تعمل

- **التجربة:** تبدأ تلقائيًا عند الموافقة على المنشأة أو إنشائها من اللوحة، بعدد أيام الإعداد (7)، على باقة التجربة (الاحترافية).
- **بعد انتهاء التجربة:** المنشأة للقراءة فقط مباشرة حتى التفعيل. يعرض مستخدموها بياناتهم ويطبعونها ويصدّرونها، ولا يضيفون ولا يعدّلون ولا يحذفون. الرفض من الخادم نفسه، لا من الواجهة فقط.
- **الاشتراك المدفوع:** بعد نهاية الفترة مهلة سماح (7 أيام) بالعمل الكامل مع تنبيه، ثم قراءة فقط. «إيقاف التجديد» يعمل حتى نهاية الفترة بلا مهلة.
- **حدود الباقة:** إضافة مستخدم أو موظف فعّال أو فرع فوق الحد تُرفض برسالة واضحة. الموجود فوق الحد لا يُحذف.
- **في القراءة فقط يبقى مسموحًا:** تعطيل الموظفين والمستخدمين الخاصين وإيقاف دخولهم، والإرسال للهيئة، وطلب الاشتراك.
- **«إرجاع إلى مشترك»** لفترة سارية أو في مهلتها فقط؛ الفترة المنتهية تُمدَّد أو يُفعَّل لها اشتراك جديد.
- **تصدير CSV** آمن من الصيغ: النص الذي يبدأ بـ = أو + أو - أو @ يُسبق بعلامة '.
- **الرصيد:** الفواتير + التسويات − المدفوعات. موجب = مستحق على المنشأة.
- **الدفع الآن يدوي:** تحوّل المنشأة المبلغ، ثم تسجّل الدفعة وتفعّل من صفحة المنشأة. الدفع الإلكتروني (Moyasar أو Tap أو PayTabs) والتجديد التلقائي في مرحلة لاحقة.
- **فواتير الاشتراك** مستندات داخلية للمنصة حاليًا، وتُطبع باسم «مطالبة اشتراك» مع سطر «ليست فاتورة ضريبية إلكترونية». ربطها بالفوترة الإلكترونية للهيئة خطوة لاحقة. **املأ بيانات المنصة في «الإعدادات» قبل أول تفعيل**: تُحفظ داخل كل فاتورة وقت إصدارها.
